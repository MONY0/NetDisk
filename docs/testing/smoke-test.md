## 数据库观察、通过和停止条件

对注册、上传、分享、删除和引用计数保存脱敏只读 SQL 观察，至少覆盖用户、文件元数据、目录、分享及跨用户引用关系。

批次只有在所有适用行均为 `Pass`、传输大小与 MD5 一致、数据库观察无矛盾，且每行 Evidence 的“实际”均为本次运行 ID 目录下可解析的文件路径并符合该行“需”项时才可通过。不得用无关证据重复充当其他行的通过证据。证据缺失、路径无法解析或结果不确定均不可通过。

数据损坏、MD5 不一致、未授权访问成功、持续崩溃、触及生产系统或无法确保磁盘演练仅影响可丢弃挂载点时，立即停止、保存脱敏证据并升级；修复后重测受影响行。
